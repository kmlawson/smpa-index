Welcome to the SMPA wiki. The purpose of this wiki is to help compile information about files within the Shanghai Municipal Police archive microfilm rolls related to the International Settlement in Shanghai. 

To read more about this collection, see this guide and index produced by the US National Archives: \\ [[https://archive.org/details/records-of-the-shanghai-municipal-police-1894-1949-microfilm-pamphlet|Records Of The Shanghai Municipal Police 1894-1949]]

===== File Lists =====

Below are pages which list files from the [[https://archive.org/details/records-of-the-shanghai-municipal-police-1894-1949-microfilm-pamphlet|NARA index]] for the collection. The workflow is as follows: 

  - With use of GPT4 as an assistant and OCR vehicle, pages from the index PDF are converted to tables for inclusion in the pages below.
  - When these are complete, each page will be proofread to look for problems with the OCR (or other LLM hallucinations)
  - Links will be added to copies of the files on the Internet Archive, either separate files there or the appropriate page in the microfilm rolls when these can be located.
  - Tags that add more clues as to topics that are covered in the document can be added to a tags cell.
  - Notes on files, which may be a summary of what they contain, or a list of various attachments that the files include can be added to a notes box. 
  - The total pages in the file can be listed for cases of longer files that are more than a few pages.
  - Files of interest can have the name of the file link to a separate page on this wiki for the file where we can add more details as needed.
  - When most of the files have been listed and linked up, a full spreadsheet of the collection, in various formats, will be available for download from this homepage.

The majority of the files are found in these four groups of documents, with the vast majority of them D Files.
